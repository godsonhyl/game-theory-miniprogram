# 全项目代码评审报告（2026-10-15）

> 评审方式：5 个专项评审（引擎 / 牌桌页 / utils 与云服务 / 首页与测试套件 / 构建发布脚本），只读。
> 本文档为归档版；修复进展见文末「修复记录」。

## 一句话结论

工程素质明显高于同类业余项目（注释纪律、失败路径意识、密钥管理、引擎守恒验证都扎实），但存在 2 个 CRITICAL（一个评估器数学 bug、一个死锁），核心风险集中在 **remoteMode 同步语义**与**文档承诺但代码未兑现的合规开关**上。修复 CRITICAL/HIGH 前不适合真实好友房对局。

## CRITICAL

## HIGH

### 牌局正确性
1. **进行中 sittingOut 蒸发边池筹码**：`buildSidePots`（poker-core.js:384）认其已投入，`showdown()`（:1119）不评估他 → 独享边池资格的池整池金额被静默丢弃（C-2 姊妹 bug，引擎层根源）。
2. **本地站起没写引擎**（table.js:1495）：站起的房主/AI 玩家每手照发牌扣盲注，甚至可能躺赢底池。

### 好友房同步协议
3. **动作 seq 跨设备时钟 + 房主单一全局 appliedSeq**（room-sync.js:40, table.js:590）：好友 B 时钟慢 1 秒 → 其所有动作被 `seq > base` 过滤静默永久丢弃，且单槽 action 无 ack/重传。
4. **payload 伪冒座位**（room-sync.js:171, table.js:747）：房主消化动作时信任 payload 里的 `seat`，任何好友可替他人行动；应以行内 `r.seat` 断言。
5. **房主崩溃后房间永久僵死**：房主从不删自己那行，好友端只判行存在性，无房主心跳 staleness 检测。
6. **镜像时序三连**（table.js:624, 946; room-sync.js:115）：倒计时每 1.5s 被重置（20s 自动行动永不触发）；快照帧无版本号乱序回滚；镜像端乐观 `game.act` 跑在无 deck 的残缺引擎上可向 board 塞 undefined。

### 合规与作弊
7. **advise() 无 practiceMode 开关**：README/CLAUDE.md 要求「好友房必须关闭行动建议」，代码未兑现——好友房轮到自己照常渲染 1800 次蒙特卡洛建议（poker-core.js:669, table.js:1975）。
8. **快照广播全体真人底牌**（poker-core.js:1274 → table.js:880 整包写库）：RLS 同房可读，一条 `cloud.database.from('poker_room_seats').select()` 即透视全场。已知边界，短期先加 hideHoles。

### 其他 HIGH
- `upload.js:121` ignores 排除 `miniprogram_npm/**` → 命令行上传的体验版缺云 SDK，白屏。
- 建房扣卡**抛异常**时房间不回滚（index.js:250-260，只处理 ok:false 分支）→ 重试泄漏房间。
- profile 页 `habit`/`favHole` 引用从未定义的字段（profile.wxml:53,57），「常用打法/最常底牌」永远渲染为空。

## MEDIUM

- **商业化硬前提**：战绩纯客户端自报（auth.js:284，total_hands 可刷 → 领手数奖励无限领）；签到三段非原子可双领（auth.js:235，last_checkin 标记失败被吞 + 客户端日期）。房卡货币化前必须服务端化。
- 排除清单三处漂移：pack.js / upload.js / project.config.json 各写一份，test-cards/test-index-logic/test-room-sync.js（49KB）会进 zip 与上传包。
- 引擎 `aiDecide` 回退路径可产非法加注（min/max 未传时 clamp 顺序错）→ 看门狗无重试上限理论上死循环（poker-core.js:578-597）。
- `preflopScore` A/K/Q 分支为死代码（r1 索引错位），AI 几乎从不 3-bet AA/KK（poker-core.js:542）。
- `check-wxml.js` 只查文本插值不查属性位置（wx:if="{{c.rank}}" 盲区）；不剥离注释；VOID_TAGS 不全。
- 牌局关键上行（心跳/就绪/站起坐下）大量 `.catch(() => {})` 无提示吞错 → 用户不知动作未达权威端（table.js:545, 2382, 1508）。
- 缺 `onHide`：切后台轮询/看门狗/倒计时照跑。
- 每帧 render 无缓存地跑 1800 次蒙特卡洛（table.js:1703），低端机掉帧。
- 好友/分享入口参数：onLoad 的 `options.room` 绕过 6 位数字校验（index.js:63）；tryJoin 无防抖；table URL 参数 `dur` 无上限、`own=1` 完全信客户端。
- 镜像端每 1.5s 全量 setData 相同负载、房主每 1.5s 全量写库（无脏检查/帧版本号）。
- 站起观战者盈亏按 1000 兜底基准算错（table.js:1284）；结算弹窗注释与代码矛盾（table.js:86 vs 1716）；裸 `catchtap` 拦截行为无保证（table.wxml:256 等）；对手座位计时环显示我的残值 tick；零筹码玩家会入局亮牌。
